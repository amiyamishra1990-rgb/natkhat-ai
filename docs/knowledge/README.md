# Knowledge Vault

**Version:** 1.0.0
**Status:** Active — structural placeholder, no entries yet (intentional at Sprint 01 start)
**Owner:** Engineering
**Last Updated:** 2026-07-28

Reusable engineering knowledge that would otherwise be lost when an
individual engineer moves on or a session ends: lessons learned,
performance findings, security discoveries, framework-specific best
practices, developer onboarding notes, and AI agent learnings.

Each subfolder holds short, dated markdown notes — not formal
documents requiring review, just durable records of what was learned
by doing. Distinct from `docs/engineering/` (which documents
_standards_) and `docs/decisions/` (which documents _why a choice was
made_).

Empty at Sprint 01 start except for this index and a README per
subfolder; content accumulates as Sprint 01 execution happens.

## Subfolders

- `lessons-learned/`
- `performance-findings/`
- `security-discoveries/`
- `flutter-best-practices/`
- `nestjs-best-practices/`
- `supabase-findings/`
- `developer-onboarding/`
- `ai-agent-learnings/`
