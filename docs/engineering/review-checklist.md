# Mandatory Engineering Review Checklist

**Version:** 1.0.0
**Status:** Active — mandatory gate for every release
**Owner:** Engineering
**Last Updated:** 2026-07-29

Enforces the Engineering Constitution's
[Mandatory Engineering Review Gates](../constitution/engineering/engineering-constitution.md#mandatory-engineering-review-gates)
(Privacy, Security, Parent Trust, Child Safety), required by the
[Child Privacy & Safety Constitution](../constitution/product/child-privacy-and-safety-constitution.md).
Every new feature or release must be able to answer **YES** to each
question below before shipping.

## Release Questions

- ✓ Privacy by Default
- ✓ Child Safety
- ✓ Parent Trust
- ✓ Secure APIs
- ✓ Audit Logging
- ✓ Search Engine Protection
- ✓ Encryption
- ✓ Parent Data Ownership
- ✓ AI Safety
- ✓ Product Constitution Compliance

**Any "NO" blocks release.** The feature returns to design and is not
released until every question above is answered YES.

This checklist is one of the seven engineering checklists scheduled
for full authorship in Sprint 01, Milestone 6
(`docs/sprints/sprint-01.md`, §15, §19); it is created now, ahead of
that milestone, because the Child Privacy & Safety Constitution makes
it a mandatory gate effective immediately.
