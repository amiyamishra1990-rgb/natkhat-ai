# Product Module Registry

**Version:** 1.1.0
**Status:** Reserved — template created, still empty of actual modules
**Owner:** Engineering
**Last Updated:** 2026-07-30

Reserved registry for future product modules. Each module's docs will
follow a fixed structure — Vision, Requirements, Architecture, APIs,
Database, Security, Testing, Deployment — defined in
[`TEMPLATE.md`](./TEMPLATE.md).

`TEMPLATE.md` was authored in Sprint 01, Milestone 5
(`docs/sprints/sprint-01.md`, §13, §15). No modules exist yet — Sprint
01 has no business features. When a module is proposed, copy
`TEMPLATE.md` to `docs/modules/<module-slug>/README.md`.
