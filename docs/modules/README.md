# Product Module Registry

**Version:** 1.3.0

Registry for product modules. Each module's docs follow a fixed
structure — Vision, Requirements, Architecture, APIs, Database,
Security, Testing, Deployment — defined in
[`TEMPLATE.md`](./TEMPLATE.md).

`TEMPLATE.md` was authored in Sprint 01, Milestone 5
(`docs/sprints/sprint-01.md`, §13, §15). When a module is proposed,
copy `TEMPLATE.md` to `docs/modules/<module-slug>/README.md`.
